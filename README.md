# Bitácora de Hacking Ético y CTF

¡Bienvenido! Este repositorio es mi bitácora personal donde documento las soluciones y *write-ups* de las máquinas de Hacking Ético y CTF (Capture The Flag) que voy resolviendo.

El objetivo principal es registrar mi progreso, solidificar conocimientos y compartir mis metodologías. Como parte de mi rutina de aprendizaje, me he propuesto el reto de resolver y documentar máquinas de distintos niveles de dificultad

## Estructura del Repositorio

La navegación es simple. Los *write-ups* están organizados por la plataforma a la que pertenecen. Dentro de cada plataforma, encontrarás una carpeta por cada máquina resuelta, la cual contiene un documento con la solución detallada.
